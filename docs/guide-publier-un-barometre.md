# Publier un baromètre

Guide pour l'équipe BIG FIVE. Aucun développeur n'est nécessaire.

Temps à prévoir : 10 minutes par baromètre.

## Avant de commencer

Préparez ces éléments :

| Élément | Règle |
|---|---|
| Titre | Une question. 110 caractères au maximum. |
| Date de parution | Le mois et l'année. |
| Périmètre | 3 éléments courts. Exemple : « 3 opérateurs télécoms ». |
| Chiffres clés | 3 chiffres. Pour chacun : la valeur, un libellé court, une phrase d'explication. |
| À retenir | Une phrase. 200 caractères au maximum. |
| Couverture | Une image. Voir les règles ci-dessous. |
| Lien du PDF complet | Pour l'équipe seulement. Il n'apparaît jamais sur le site. |

## L'image de couverture

| Règle | Valeur |
|---|---|
| Format | 16:9 (image plus large que haute) |
| Taille conseillée | 1600 × 900 pixels |
| Largeur minimale | 1000 pixels (le site refuse une image plus petite) |
| Type de fichier | JPG ou PNG |
| Poids maximal | 500 Ko (le site refuse une image plus lourde) |
| Contenu | Aucun lien, aucune adresse web et aucun QR code imprimés dans l'image |

Pour alléger une image trop lourde, utilisez un outil gratuit comme [Squoosh](https://squoosh.app).

> [À COMPLÉTER : format de couverture à confirmer. La maquette du 3 novembre affiche une couverture en hauteur (1121 × 1403). Le site accepte les deux formats.]

## Les étapes

### 1. Se connecter

1. Ouvrez `https://bigfive.solutions/admin`.
2. Saisissez votre e-mail et votre mot de passe.

### 2. Créer la fiche

1. Dans le menu de gauche, cliquez sur **Baromètres**.
2. Cliquez sur le bouton de création, en haut de la liste.

### 3. Remplir la fiche

1. **Identifiant** : écrivez `secteur-pays-année-mois`, en minuscules, sans accent.
   Exemple : `telecoms-ci-2026-08`.
   Cet identifiant devient l'adresse de la page : `bigfive.solutions/barometres/telecoms-ci-2026-08`.
   Ne le changez plus après la publication.
2. **Date de parution** : choisissez le mois.
3. **Titre** : écrivez la question.
4. **Titre pour Google** : écrivez un titre de 60 caractères au maximum.
   Mettez-y le secteur et le pays. Exemple : « Baromètre télécoms Côte d'Ivoire, août 2026 | BIG FIVE ».
   C'est ce titre que les internautes voient dans Google. Il aide votre page à être trouvée.
5. **Périmètre** : ajoutez les 3 éléments.
6. **Chiffres clés** : ajoutez les 3 chiffres.
7. **À retenir** : écrivez la phrase.
8. **Couverture** : cliquez sur **Sélectionnez un fichier**, puis envoyez l'image.
   Dans le champ **Texte alternatif**, décrivez l'image en une phrase.
9. **Ressource interne** (colonne de droite) : collez le lien du PDF complet.

### 4. Vérifier

1. Cliquez sur **Enregistrer le brouillon**.
2. Cliquez sur **Aperçu**.
3. Relisez la page : titre, chiffres, image.

Le brouillon n'est pas visible par le public.

### 5. Publier

Vous avez deux choix :

- **Publier tout de suite** : cliquez sur **Publier**.
- **Programmer** : cliquez sur la flèche à côté de **Publier**, puis sur **Programmer la publication**. Choisissez le jour et l'heure.

Une publication programmée part au prochain passage automatique du site. Ce passage a lieu une fois par jour, à 6 h (heure d'Abidjan).

## Ce qui se passe après la publication

- Le nouveau baromètre s'affiche en tête de la section Observatoire de l'accueil.
- Le baromètre précédent descend dans « Baromètres précédents ».
- Le baromètre a sa propre page.
- Il apparaît dans la liste : `bigfive.solutions/barometres`.
- Google est prévenu par le plan du site, mis à jour tout seul.

## Corriger ou retirer un baromètre

- **Corriger** : ouvrez la fiche, modifiez, cliquez sur **Publier les modifications**. Le site se met à jour tout de suite.
- **Retirer** : ouvrez la fiche, puis cliquez sur **Annuler la publication**. La page disparaît du site.

## Le PDF complet

- Le lien du PDF est visible seulement par les personnes connectées à l'administration.
- Il n'est jamais envoyé au navigateur d'un visiteur.
- Un visiteur qui veut le baromètre remplit le formulaire « Obtenir le baromètre ». L'équipe reçoit sa demande par e-mail et le recontacte.

## En cas de problème

| Message | Solution |
|---|---|
| « L'image dépasse 500 Ko » | Allégez l'image, puis renvoyez-la. |
| « L'image doit faire au moins 1000 px de large » | Exportez l'image en plus grand. |
| « Format attendu : secteur-pays-année-mois » | Vérifiez l'identifiant : minuscules, tirets, pays sur 2 lettres, année, mois sur 2 chiffres. |
| Le baromètre programmé n'apparaît pas | Attendez le passage de 6 h, ou cliquez sur **Publier**. |
